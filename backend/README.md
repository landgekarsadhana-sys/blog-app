# 📝 Blog App (Full Stack Project)

A full-stack Blog Application built using **MERN stack (MongoDB, Express, React, Node.js)**.

---

## 🚀 Features

- Create blog posts
- Read all posts
- Update posts
- Delete posts
- Responsive frontend UI
- REST API backend
- MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- Vite
- CSS

### Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
