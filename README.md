# Blog App

A full-stack blog application built using modern web technologies.

## Features

* User Authentication
* Create, Edit & Delete Blogs
* Responsive UI
* Backend API Integration
* Database Connectivity

## Tech Stack

### Frontend

* React.js
* CSS / Tailwind

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Installation

```bash
git clone https://github.com/landgekarsadhana-sys/blog-app.git
cd blog-app
```

## Run Frontend

```bash
cd frontend
npm install
npm start
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```
